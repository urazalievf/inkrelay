Yearly Pro keys.

- A Pro key can carry an end date. Two weeks before it, the menu says the renewal key is on its way, with a reminder a week before and on the last day.
- Each renewal emails a new key. Enter it from the InkRelay menu or with inkrelay license enter, and nothing pauses.
- If a key runs out, the Pro parts pause as before, and InkRelay asks for the renewal instead of calling the key refused. Your notes are safe.
- Founder keys never end.
