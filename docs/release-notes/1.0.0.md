InkRelay is now free and open source.

- Every feature is included for everyone: Viwoods Cloud, Kindle Scribe by email, Google, Microsoft and Notion, the review stack on Mac, iPhone and iPad, and AI transcription with your own key. There is no license key, trial or subscription any more.
- The code is on GitHub under the MIT license: github.com/urazalievf/inkrelay
- The markers InkRelay writes around its block in Obsidian notes now use a plain hyphen. Notes written before keep their block and get the new marker the next time they sync.
